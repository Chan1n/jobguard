# JobGuard — ตรวจเบื้องต้นก่อนกด ก่อนรัน

ต้นแบบภาษาไทยสำหรับนักศึกษาและเด็กจบใหม่ ตรวจ URL และไฟล์จากการสมัครงานในเบราว์เซอร์ด้วย Next.js / TypeScript ไม่มี API หรือฐานข้อมูลเซิร์ฟเวอร์ ไม่เปิด URL ไม่ตาม redirect ไม่อัปโหลด เปิด รัน หรือแตกไฟล์

## ติดตั้งและรัน

ต้องมี Node.js 20.9 ขึ้นไป และ npm (ทดสอบจริงด้วย Node 26.11.1 / npm 11.20.0 บน macOS)

```sh
npm ci
npm run dev
```

เปิด http://127.0.0.1:3000 หรือ http://localhost:3000 ข้อมูลและ dependencies เตรียมไว้แล้วในเครื่องนี้ หลังติดตั้งเสร็จไม่ต้องเชื่อมอินเทอร์เน็ตเพื่อใช้ผ่าน localhost

```sh
npm test
npm run typecheck
npm run build
```

`npm run build` ส่งออกเว็บสแตติกไป `out/` จึง **ไม่ใช้ `next start`** สำหรับงานนี้ หากต้องการใช้เวอร์ชัน build และมี Python 3:

```sh
python3 -m http.server 3000 --bind 127.0.0.1 --directory out
```

นำ `out/` ไปโฮสต์ได้ แต่ต้องใช้ HTTPS เพราะใช้ Web Crypto นอก localhost ยังไม่รองรับการเปิดเว็บใหม่แบบออฟไลน์บนเว็บโฮสต์ ไม่มี service worker

## กระบวนการ

1. เลือกแท็บ URL หรือไฟล์ → วางข้อความ/URL หรือเลือกไฟล์หนึ่งไฟล์
2. ตรวจและอ่านหลักฐาน ที่มา วันที่ชุดข้อมูล และข้อจำกัด
3. เลือกการตัดสินใจเพื่อบันทึก → กลับมาดูหรือเปลี่ยนการตัดสินใจในประวัติ
4. ล้างประวัติได้ เก็บสูงสุด 100 รายการในเบราว์เซอร์และ origin เดิม

URL รองรับ HTTP/HTTPS สูงสุด 5 ลิงก์ ใช้ URL parser ทั้งตอนเตรียมข้อมูลและตรวจจริง ทำ host เป็นตัวเล็ก ตัด fragment คง scheme/path/query ไม่เรียง query และไม่เหมารวมทั้งโดเมน URL ซ้ำในข้อความเดียวตรวจครั้งเดียว นับเพดานก่อนตัดซ้ำ URL ในข้อความต้องคั่นด้วยช่องว่าง ไม่ตัดเครื่องหมายท้าย URL โดยเดา เพราะอาจเป็นส่วนของ path/query จริง

ไฟล์จำกัด 20 MB คำนวณ SHA-256 ด้วย Web Crypto ตรวจ signature PDF/JPEG/PNG และ Windows PE (MZ + e_lfanew ที่อยู่ในขอบเขต + PE signature และพื้นที่ COFF header) ไม่ตรวจความสมบูรณ์ของเอกสารหรือ PE ทั้งไฟล์ ZIP ระบุได้เพียงโครงสร้าง ZIP ไม่อ้าง APK/DOCX ไฟล์อื่นยังตรวจแฮชได้

ประวัติไม่เก็บชื่อไฟล์ ไฟล์ URL เต็ม หรือข้อความแชท ใช้ SHA-256 เป็นรหัสตรวจซ้ำ บันทึกรหัส ประเภท เวลา ผลย่อ เวอร์ชันชุดข้อมูล การตัดสินใจและเวลาที่บันทึก SHA-256 ไม่ใช่การเข้ารหัสและไม่ป้องกันการเดา URL ที่ทราบอยู่แล้ว ผลตรวจเต็มอยู่ในหน่วยความจำจนเปลี่ยนแท็บ/ตรวจใหม่/โหลดหน้า

## ข้อมูลจริงและใบอนุญาต

ใบอนุญาตข้อมูลและฟอนต์รวมใน `public/licenses/` เพื่อให้ติดไปกับ static build ด้วย

ดู `data/threats.json` สำหรับ URL แฮช แหล่งข้อมูล ไฟล์ต้นทาง commit วันที่ดาวน์โหลด จำนวน และเวอร์ชัน

- Phishing.Database: URL จาก `phishing-links-ACTIVE.txt` 5,000 รายการ หลัง parse → normalize → unique → sort → เลือก 5,000 แรก แนบ MIT ใน `data/licenses/Phishing-Database.txt`
- ESET malware-ioc: SHA-256 ทั้ง 41 รายการจาก `deceptivedevelopment/samples.sha256` แนบ BSD-2-Clause ใน `data/licenses/eset.txt`
- สำเนาดาวน์โหลด 27 ตุลาคม 2026 ไม่อัปเดตอัตโนมัติ URL ชุดย่อยไม่เป็นตัวแทนภัยทั้งหมด ไม่รับประกันว่าปลายทางยังเป็นภัยในปัจจุบัน
- ไม่มีการดาวน์โหลดตัวอย่างมัลแวร์ ข้อมูลทดสอบที่สร้างเองแยกใน `tests/fixtures/`

อัปเดตข้อมูลด้วย `node scripts/prepare-data.mjs` (ต้องมีอินเทอร์เน็ต) สคริปต์ยึด commit ก่อนดาวน์โหลดข้อมูลและใบอนุญาต ควรเปลี่ยน dataset version เมื่อปรับชุดข้อมูล ตรวจ diff/จำนวน/ใบอนุญาต ทดสอบและ build ใหม่ก่อนแจกจ่าย

## โครงสร้าง

- `app/`: หน้า Next.js และ CSS ที่รองรับมือถือ ไม่มี CDN/font ภายนอก
- `components/`: ฟอร์ม ผลตรวจ การตัดสินใจ และประวัติ
- `lib/checkers.ts`: URL, SHA-256, file signature
- `lib/history.ts`: schema ประวัติและ localStorage
- `data/`: ข้อมูลจริงและใบอนุญาต

ใบอนุญาตข้อมูลและฟอนต์รวมใน `public/licenses/` เพื่อให้ติดไปกับ static build ด้วย
- `tests/`: ทดสอบและ fixtures ที่สร้างเอง
- `docs/`: สรุปโครงการสองหน้า บันทึก AI ผลทดสอบจริงและภาพหลักฐาน

## ข้อจำกัดและงานต่อยอด

ไม่พบรายการ **ไม่ได้แปลว่าปลอดภัย** เครื่องมือไม่ตรวจพฤติกรรม ไม่ตรวจความหมายของข้อความ ไม่เปิดเอกสาร ไม่วิเคราะห์ archive และไม่ให้ verdict ความปลอดภัย ทั้งแหล่ง URL และงานวิจัย ESET มีความครอบคลุมจำกัด ไฟล์ที่เปลี่ยนหนึ่งไบต์จะมีแฮชใหม่ การใช้มือถือจริงและไฟล์ 20 MB ยังต้องทดสอบประสิทธิภาพเพิ่มเติม

ยังไม่มีการสัมภาษณ์/ทดลองกับนักศึกษา 60 คนหรือเก็บผลโครงการจริง เป้าหมาย 80% และงบ 30,000 บาทเป็นแผนเสนอ ไม่ใช่ผลประเมินหรือราคาได้รับยืนยัน

งานต่อยอด: ระบบอัปเดตข้อมูล เพิ่มแหล่งข้อมูล/ชนิดไฟล์ ทดสอบหลายเบราว์เซอร์และอุปกรณ์จริง ปรับ accessibility ของแท็บให้รองรับปุ่มลูกศร ส่งออกสรุปแบบไม่ระบุตัวตน และ offline service worker พร้อมนโยบายอัปเดต
